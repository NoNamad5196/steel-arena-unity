# 넥토리얼 제출 체크리스트

## 제출 파일

- [ ] Windows 또는 WebGL 실행 빌드
- [ ] 60~90초 플레이 영상
- [ ] 소스 저장소 링크
- [x] 프로젝트 README
- [x] 게임 규칙 문서
- [x] 개발 의사결정 기록
- [x] 테스트 코드
- [x] AI 활용 범위 공개

## 영상 구성안

1. 0~8초: 한 문장 소개와 전체 흐름
2. 8~20초: 동력 맞추기와 점수에 따른 보상 품질
3. 20~35초: 3개 중 1개 선택, 조합 완성 표시
4. 35~55초: 고철 돌격병 전투와 파쇄 대장 등장
5. 55~70초: 조합 효과 발동과 피해 숫자
6. 70~85초: 결과 화면과 핵심 코드 구조

## 면접 전 확인

- [ ] `CalibrationSession`의 점수 계산식을 설명할 수 있다.
- [ ] `UpgradeCatalog`이 조합 후보를 보장하는 방식을 설명할 수 있다.
- [ ] `RunBuild`와 `AutoBattleSimulation`을 분리한 이유를 설명할 수 있다.
- [ ] 일반 적과 보스의 밸런스 차이를 수치로 설명할 수 있다.
- [ ] 생성형 AI가 만든 코드에서 직접 수정하거나 폐기한 사례를 설명할 수 있다.
- [ ] 모든 테스트가 Unity Test Runner에서 통과한다.
- [ ] 빌드된 실행 파일을 다른 PC에서 직접 실행해 본다.

## 소개 문장

> 미니게임 실력이 보상 품질로 이어지고, 선택한 강화 조합이 2연전 자동 전투에서 실제로 발동하는 Unity 2D 프로토타입입니다. 생성형 AI로 제작 속도를 높이되, 게임 루프 피벗과 구조 설계, 밸런스 검증은 직접 수행했습니다.
