# 강철 투기장 — 미니게임 기반 오토배틀러 MVP

## 한 줄 설명

짧은 코어 조율 미니게임으로 전투 모듈을 획득하고, 완성한 빌드가 자동전투에서 작동하는 모습을 관찰하는 2D 런 기반 오토배틀러.

## 핵심 감정

1. 미니게임을 잘해서 더 강한 보상을 얻는다.
2. 세 장 중 한 장만 골라 이번 런의 빌드를 만든다.
3. 선택한 강화가 전투에서 발동하는 순간을 확인한다.

## MVP 흐름

```text
강화 준비
→ 동력 맞추기 (3회 입력)
→ 강화 선택 (3개 중 1개)
→ 위 과정을 총 3라운드
→ 고철 돌격병
→ 파쇄 대장 보스전
→ 전투 결과
→ 새 도전
```

## 미니게임 리턴

- 커서를 목표 구간에 멈추는 입력을 3회 수행한다.
- 평균 정확도를 C/B/A/S 등급으로 변환한다.
- 점수는 보상 수치의 0.8~1.4배 품질에 반영된다.
- 보상 후보 세 개는 서로 다르며, 이미 획득한 모듈은 다시 나오지 않는다.
- 플레이어가 한 장을 선택하면 다른 두 장은 폐기된다.

## 보상 풀

- 튼튼한 장갑: 최대 체력 증가
- 강화 무기: 공격력 증가
- 고속 장전기: 공격 속도 증가
- 가속 장치: 이동 속도 증가
- 비상 수리: 체력 35% 이하에서 한 번 회복
- 연속 공격: 세 번째 공격마다 추가 피해
- 탄막 증폭기: 네 번째 공격마다 추가 피해
- 반격 장갑: 받은 피해 일부를 반사
- 돌진포: 전투 첫 공격에 추가 피해

## 강화 조합

- 고속 장전기 + 탄막 증폭기: 탄막이 네 번째가 아닌 세 번째 공격마다 발동한다.
- 튼튼한 장갑 + 반격 장갑: 반사 피해가 50% 증가한다.
- 가속 장치 + 돌진포: 첫 공격 추가 피해가 50% 증가한다.
- 조합에 필요한 강화 하나를 보유하면 다음 보상 세 장 중 최소 한 장은 짝 강화로 제안한다.

## 전투 구성

- 1전투 `고철 돌격병`: 체력은 낮지만 빠르게 접근하고 자주 공격한다.
- 2전투 `파쇄 대장`: 체력이 높고 세 번째 공격마다 강타하는 보스다.
- 각 전투 시작 시 플레이어 체력과 일회성 효과는 초기화된다.
- 결과 화면에서 격파 수, 누적 피해, 회복량, 조합 효과 발동 횟수를 확인한다.

## 화면 표현 원칙

- 화면에 보이는 명칭과 안내는 쉬운 한국어를 우선한다.
- 보상 카드에는 강화 전 수치와 강화 후 수치를 함께 표시한다.
- 생존/공격/속도 강화는 카드 색상으로 구분한다.
- 동력 맞추기는 시작 카운트다운, 완벽 구간, 3회의 개별 점수를 표시한다.
- 자동 전투에서는 공격 동작, 피격 흔들림, 회복 반응, 피해 숫자로 강화 효과를 확인할 수 있어야 한다.

## MVP 제한

- 미니게임 1종
- 준비 라운드 3회
- 보상 9종과 조합 3종
- 일반 적 1명, 보스 1명
- 메타 성장, 저장, 희귀도, 리롤 없음
