# 강철 투기장

미니게임 성과로 강화 부품을 얻고, 선택한 조합이 자동 전투에서 작동하는 과정을 관찰하는 2D 오토배틀러 프로토타입입니다.

## 플레이 흐름

```text
동력 맞추기 3회
→ 강화 3개 중 1개 선택
→ 총 3라운드 반복
→ 고철 돌격병 전투
→ 파쇄 대장 보스전
→ 결과와 조합 효과 확인
```

조작은 마우스 클릭 또는 스페이스바만 사용합니다.

## 핵심 구현

- 미니게임 평균 점수가 보상 효과의 0.8~1.4배 품질로 연결됩니다.
- 이미 획득한 강화는 다시 등장하지 않습니다.
- 조합에 필요한 강화 하나를 획득하면 다음 보상 후보에 짝 강화가 최소 하나 등장합니다.
- 전투 시뮬레이션은 화면 표시와 분리되어 Edit Mode에서 독립적으로 검증할 수 있습니다.
- 두 적은 체력, 이동 속도, 공격 주기, 강타 주기가 서로 다릅니다.
- 전투 배경은 생성형 이미지 도구로 제작했으며 프로젝트 안에 원본 프롬프트를 기록했습니다.
- 효과음은 외부 음원 없이 런타임에 파형을 합성합니다.

## 강화와 조합

| 강화 | 기본 효과 | 조합 효과 |
|---|---|---|
| 고속 장전기 + 탄막 증폭기 | 공격 속도 증가, 네 번째 공격 강화 | 탄막이 세 번째 공격마다 발동 |
| 튼튼한 장갑 + 반격 장갑 | 최대 체력 증가, 받은 피해 반사 | 반사 피해 50% 증가 |
| 가속 장치 + 돌진포 | 이동 속도 증가, 첫 공격 강화 | 돌진포 추가 피해 50% 증가 |

독립 강화로 `강화 무기`, `비상 수리`, `연속 공격`이 있습니다.

## 코드 구조

```text
CalibrationSession
    └─ 미니게임 진행과 점수 계산

UpgradeCatalog ── RunBuild
    ├─ 보상 생성      ├─ 현재 능력치
    └─ 조합 후보 보정  └─ 활성 조합 판정

EnemyCatalog ── AutoBattleSimulation
    ├─ 적별 전투 데이터 ├─ 이동/공격/회복
    └─ 일반 적/보스     └─ 연속 공격/탄막/반격/돌진포

ProtocolArenaGame
    ├─ 게임 상태 전환
    └─ UI 이벤트 연결

UI
    ├─ UpgradePresentation
    ├─ FighterView / HealthBarView
    └─ ProceduralAudio / RuntimeUIFactory
```

## 실행 환경

- Unity 6000.6.0f1
- Universal 2D
- Input System
- macOS Apple Silicon에서 개발

프로젝트를 Unity로 연 뒤 `Assets/Scenes/SampleScene.unity`를 열고 Play를 누르면 됩니다. 별도의 Inspector 연결은 필요하지 않습니다.

## 검증

- 미니게임 점수와 보상 배율 경계
- 중복 없는 3개 보상 후보
- 조합 짝 강화 제안
- 강화 적용에 따른 능력치 변화
- 일반 적과 보스의 전투 데이터 차이
- 기본 기체 패배 및 강화 기체 승리
- 미니게임부터 새 도전까지 전체 플레이 흐름

순수 전투 로직은 화면이나 프레임 속도와 독립적으로 시뮬레이션할 수 있습니다.

## 개발 과정과 AI 활용

첫 버전은 행동 규칙을 직접 편집하는 전투 실험이었습니다. 플레이 과정에서 규칙 편집은 기술 시연에는 적합하지만 보상 획득과 성장의 기대감이 약하다고 판단했습니다. 기존 기능을 유지 확장하지 않고 `미니게임 → 3개 중 1개 보상 → 빌드 조합 → 자동 전투` 구조로 전면 교체했습니다.

생성형 AI는 구현 초안, 반복 수정, 테스트 항목 탐색과 배경 제작에 활용했습니다. 게임의 목표 설정, 피벗 결정, 기능 범위, 명칭, 밸런스 기준과 최종 검수는 개발자가 직접 결정한다는 원칙으로 진행했습니다. AI가 생성한 결과는 컴파일과 시뮬레이션 테스트를 거쳐 채택하거나 폐기했습니다.

세부 의사결정은 `Docs/DEV_NOTES.md`, 현재 게임 규칙은 `Docs/GAME_DESIGN.md`에 정리되어 있습니다.

## 현재 범위

이 프로젝트는 완성형 서비스가 아니라 핵심 재미와 코드 구조를 보여 주기 위한 포트폴리오 프로토타입입니다. 메타 성장, 저장, 온라인 기능, 과금 요소는 포함하지 않습니다.
